# Decision Framework Skill

## 後悔最小化フレームワーク（Regret Minimization Framework）

Jeff Bezosが提唱する意思決定フレームワーク。
「80歳の自分が人生を振り返ったとき、どちらの選択をしなかったことをより後悔するか？」を問いに意思決定を行う。

## 評価の6軸

| 軸 | 説明 |
|---|---|
| 感情的後悔リスク | やらなかった後悔 vs やった後悔。行動しなかった後悔の方が長く続きやすい。 |
| 機会損失 | その選択をしないことで永遠に失われる機会はあるか。 |
| 可逆性 | やり直しがきくか。不可逆な選択ほど慎重に検討すべき。 |
| 成長可能性 | 5年後の自分のスキル・経験・人脈にどう影響するか。 |
| 周囲への影響 | 家族・チーム・コミュニティへの波及効果。 |
| 直感スコア | ユーザーが無意識に望んでいる選択を文章のトーンから推定。 |

## 使い方

1. 迷っている決断を一言で表現する
2. 選択肢を2つ（A/B）に絞る
3. 現在の年齢を入力する
4. AIが6軸で評価し、後悔リスクスコアを算出する
5. タイムライン（1年後・5年後・10年後・80歳）で将来を可視化する
